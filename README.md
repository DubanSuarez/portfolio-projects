# Portfolio Projects

Portafolio profesional que reúne proyectos enfocados en Ingeniería de Sistemas, desarrollo web (front-end y back-end), gestión de bases de datos y diseño UX/UI orientado a la experiencia del usuario.

Link: https://dubansuarez.github.io/portfolio-projects/

## Enfoque

Este repositorio contiene soluciones prácticas y académicas que integran:

- Desarrollo de aplicaciones web completas  
- Diseño de interfaces centradas en el usuario (UX/UI)  
- Modelado y gestión de bases de datos  
- Implementación de funcionalidades dinámicas con tecnologías modernas  

## Tecnologías utilizadas

- HTML, CSS, JavaScript  
- PHP y MySQL  
- Bootstrap  
- Herramientas de diseño UX/UI  

## Contenido

Cada proyecto incluido en este portafolio aborda problemáticas reales, aplicando buenas prácticas de desarrollo, diseño y estructuración de software.
